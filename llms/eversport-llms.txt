# Eversports

> Eversports is a European sports and fitness activity platform (founded 2013, Vienna, Austria). Its consumer marketplace lets people discover, book, and pay for classes, courts, and memberships, while Eversports Manager is the studio-management SaaS venues use to run schedules, bookings, and payments. For developers, Eversports exposes a read-only GraphQL Provider API (activity schedules, venues, teachers, checkout links) and a legacy JSON:API REST integration API (users, venues, courts, orders).

This llms.txt is generated by the API Evangelist enrichment pipeline from the Eversports public developer surface and a live GraphQL introspection of the Provider API. It is not published by Eversports.

## APIs

- [Eversports Provider API (GraphQL)](https://provider-api.eversportsmanager.io/api/graphql): Read-only GraphQL API for activity schedules, activity groups, venues, companies, teachers, and per-activity checkout links. Requires provider credentials.
- [Eversports Integration API v2 (JSON:API REST)](https://api.eversport.at/v2): Legacy aggregator/partner integration for users, venues, courts, and orders (application/vnd.api+json).
